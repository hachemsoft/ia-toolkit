# SDLC workflow

Generated by scripts/workflows.py from commands/: an index, never a prompt. The levels quick, standard and full
are defined once, in the kit context. A small question gets a direct answer, without this workflow.

| Step | Command | Skills | Artifact | Installed |
| --- | --- | --- | --- | --- |
| Plan | `/intent` | grilling, domain-modeling | intent.md | default |
| Plan | `/map` | wayfinder | decision tickets | optional |
| Design | `/spec` | to-spec, domain-modeling | spec.md | default |
| Build | `/build` | tdd, code-review | diff + tests (plan.md for a full change) | default |
| Build | `/design` | codebase-design, prototype | interface sketch or prototype | optional |
| Test | `/test` | tdd | verification output | default |
| Deploy | `/review` | code-review | review findings | default |
| Deploy | `/ship` | mr | MR description | default |
| Maintain | `/diagnose` | diagnosing-bugs | root cause + regression test | default |
| Maintain | `/triage` | ticket-sorting | agent-ready issues | optional |
