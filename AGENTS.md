# AI Kit

The kit itself: an engine (`installer/`) and its content (commands, skills, agents, hooks, context) installed into Gemini
CLI, Antigravity CLI, Codex CLI and Claude Code, on Mac, Windows and Linux, without administrator rights.

## Commands
- Versions: Python 3.11+ (`pyproject.toml`), standard library in the engine, `packaging/runtime.txt` for the interface wheels; ruff 0.6.9
- Install from this folder (the person runs it, never the agent): `ai-kit sync --offline`
- Checks before a merge request, budgets, adding a component, releasing: `docs/extending.md`

## Verifying your work
Test what changed and what depends on it. The full suite runs in CI on Linux, macOS and Windows.

Run tests through `scripts/offline_tests.py`, never `python -m unittest tests.<name>`: the test files import helpers from `tests/`, and the script takes every model CLI off the PATH.

1. Changed files: `git diff --name-only main...HEAD` plus `git status --short`. Base branch: `main`.
2. Run the "Changed" command of each row touched; the "Full" one when a shared file changed: `installer/core.py`,
   `installer/settings.py`, `templates/kit-context.md`, `tests/presets.py`, `scripts/offline_tests.py`, `pyproject.toml`.
3. Say in one line which scope you ran and why. Paste the real output.
4. Never run `evals/run.py --confirm-paid-run` without the person's agreement for that run.

## Conventions
- English everywhere in the repo, generic and public: no company, person, internal project or internal tool name, not even split (since 2026-11).
- A general page names no CLI outside a table; CLI-specific text goes to `docs/cli/` (`tests/test_consistency.py`).
- Commit message: the version first when there is one (`AI Kit X.Y.Z: …`), else the area (`evals: …`, `tests: …`, `docs: …`, `CI: …`); one sentence of what changed and why.
- Decisions that are hard to reverse: `docs/adr/`, indexed in `docs/adr/README.md`.

## Architecture
- `installer/` the engine (one neutral plan, one adapter per CLI in `installer/adapters/`); `runtime/` the hooks and scripts installed under `~/.ai-kit/bin`; `commands/`, `skills/`, `agents/`, `templates/`, `context/` the content; `evals/` the paid behaviour evals; `tests/` the model-free suite.
- `tests/golden/install-snapshot.json` and `versions.lock.json` are generated: regenerate them, never edit them by hand.
- `workflows/*.md` are generated by `scripts/workflows.py --write`.

## Things the agent gets wrong
- Several sessions share this checkout: before committing, `git diff` each file you add; never stage another session's hunks; a shared file is committed once both sessions are done (since 2026-11: two sessions edited `evals/run.py` and `runtime/prove_test.py` at the same time).
- A test writes in a temporary copy, never in the repository (`content_from()` for the content): the suite runs in parallel (since 2026-11: a Team layer written into `context/` broke other test files).
- Changing an installed file (`commands/`, `skills/`, `templates/`, `runtime/`, `CHANGELOG.md`) means regenerating the snapshot in the same change, and it ships in a version: `VERSION`, `pyproject.toml`, a CHANGELOG section (`docs/extending.md`, Releasing); changing a skill or agent also means raising its `aikit-version` and `python3 scripts/versions.py --update` (commands have no version of their own) (since 2026-11: CI failed on both).
- An eval criterion matches observable facts (files, `git` state) before words; widen a pattern only when the answer behaves right, and check the earlier answers keep their verdict with `python3 evals/rescore.py <reports>` (since 2026-11: five criteria missed correct answers).
- Push tags one at a time, after the commit's CI; never move a tag (since 2026-11: several tags at once triggered no pipeline).
- Windows runs differently: a test that removes a Git folder uses `remove_repository` (read-only object files); a copied `python.exe` does not start away from its DLLs (since 2026-11: the 4.23.0 and 4.23.1 Windows jobs failed).
- Gemini CLI and Antigravity runs are billed on the team's Vertex project: one targeted case at most, only with the person's agreement (since 2026-11).
